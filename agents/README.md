# 技能元数据目录

`agents/` 存放供技能检查工具或发布流程使用的静态元数据，以及本目录的说明文档。

| 文件 | 职责 |
| --- | --- |
| `interface.yaml` | 技能展示名称、简短说明、默认提示，以及兼容性、执行方式和信任声明；Yao 结构验证器按此路径读取 |
| `_meta.json` | 发布来源的 ownerId、slug、version 和 publishedAt；保留来源记录，字段内容不代表当前代码已经重新发布 |
| `README.md` | 本目录允许的文件类型、各文件职责和外部工具路径要求 |

不得在本目录保存执行脚本、渠道配置、测试用例、评估报告、运行日志或凭据。运行配置放在对应功能模块，代码测试放在 `scripts/tests/`，技能评估放在 `scripts/evals/`，任务中间结果放在根目录 `.work/`。

`interface.yaml` 中的声明只描述技能预期使用方式，不能作为客户端实际强制执行这些声明的证据。

本项目内部不读取 `_meta.json`。依赖技能根目录 `_meta.json` 的外部安装器或发布器，需要在其打包配置中将本目录文件映射到要求的位置。当前没有验证这类外部工具的安装或发布兼容性。
